\# Barbearia App



Plataforma web de agendamento e gestão para barbearia.



\## Status



Em desenvolvimento.



\## Objetivo



Permitir que clientes realizem agendamentos online e que a equipe da barbearia gerencie:



\- Serviços

\- Barbeiros

\- Horários

\- Agendamentos

\- Pagamentos

\- Clientes

\- Relatórios



\## Stack



\- Next.js

\- TypeScript

\- PostgreSQL

\- Prisma

\- Tailwind CSS

\- shadcn/ui



\## Desenvolvimento



Este projeto segue um fluxo baseado em Git, GitHub, Pull Requests e Conventional Commits.



> Nunca commite arquivos `.env` ou qualquer credencial real.
